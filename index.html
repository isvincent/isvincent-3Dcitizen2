02 民法的權利主體、權利客體與物權定義（P.109-110）

  • ▸ 權利主體 vs 權利客體：民法以「人」為權利主體、以「物」為權利客體。權利客體是指受權利主體支配之各項權利的對象或內容，不僅包括有形的「物」，也包括專利權、著作權等精神產物。
  • ▸ 物權（Real Right）：指權利主體對物直接支配、享受其利益，並具有排他性的權利，而「所有權」為物權的一種。
  • ▸ 所有權（Ownership）：指所有權人可以自由地使用、收益、處分所有物，並且排除他人干涉的權利。

（一）國家為什麼需要保障所有權？（P.110）

保障人民私有財產的所有權是現代市場經濟制度的核心。當物的所有權界定清楚後，人們可以透過交易來分配各自擁有的物品，達成彼此最大利益並滿足雙方需求。

我國《憲法》第15條規定人民之財產權應予保障。然而，為了維護公共利益，國家必須藉由正當程序對所有權加以限制，因此所有權並非受到絕對的保護。

（二）所有權保障如何減少對他人的負面影響？

若自然資源屬於無主物，當有人因私利排放廢水汙染河川生態時，全體人民只能接受環境公害。從社會契約論的觀點出發，國家的出現源於人民讓渡部分權利以追求全體利益極大化，因此自然資源歸於政府的財產，具有支配、管理河川的權力，透過法律規範防止環境公害，或透過協商加以處理。

PROP 01 自行決定如何使用
1. 直接支配性

所有權人對所有物有直接支配的權利，不需要其他人的同意或許可，可依照自己的意思占有、使用、收益與處分標的物（自用、送人或賣掉）。

PROP 02 可主張物品的所有
2. 保護絕對性

所有權屬於絕對權，意即所有權人可以向任何人（不特定人）主張所有權，任何人都不得干涉他人的所有權行使。

PROP 03 排除他人所有權主張
3. 排他性（一物一權）

一個物品只會有一個所有權，不會同時存在兩個所有權。但同一個所有權可能由數人共享，即「共有」。

4. 優先性：當「契約債權」與「所有權（物權）」衝突時誰優先？

除法律另有規定外，對於同一物的所有權會優先於債權。請點擊下方三幕全息紀錄，追蹤小辰、元元與阿庭的權利變化：

📖 課本小辭典（P.112）：債權相對性 vs 物權絕對性
🛡️ 物權絕對性（Absolute Effect）： 物權是得對「不特定人」主張之權利，屬於絕對權。阿庭因受領電腦「交付」而優先取得所有權，可對抗包含元元在內的任何人。
🔗 債權相對性（Relative Effect）： 債權是僅得對「特定人」主張之權利，只有相對效力。小辰、元元雙方成立買賣契約，由於是債權契約，不能對抗優先取得電腦所有權的阿庭。
🤔 課本 P.112 請想想看 Q1
1. 為什麼物權須優先於債權？倘若法律不是這樣規範，對於阿庭會有什麼影響呢？
系統解析：因為債權契約原則上不須公開，外人無從得知小辰私下先答應賣給元元；而物權透過「交付（占有）」或「登記」具有公示外觀。若債權優先於物權，善意購買並已拿到電腦的阿庭隨時可能被不知名的第三人追討電腦，將導致沒有人敢安心買東西，嚴重破壞市場「交易安全」與經濟運作效率！
🤔 課本 P.112 請想想看 Q2
2. 日常買賣契約原則上雙方同意即成立，不須書面，倘若一方反悔會有什麼影響？買賣雙方權益該如何保障？
系統解析：口頭或通訊軟體約定雖已成立契約，但若一方反悔，常面臨「舉證困難」或標的物被轉賣交付他人的風險。為保障權益，雙方可透過：① 保留對話紀錄或簽訂書面契約、② 約定給付「定金」或「違約金」、③ 採取「銀貨兩訖（同時履行）」儘速完成交付以取得物權！

📜 STATUTE CODE // P.113 有權利必有救濟（Ubi jus, ibi remedium）
《民法》第 767 條：「所有人對於無權占有或侵奪其所有物者，得請求返還之。對於妨害其所有權者，得請求除去之。有妨害其所有權之虞者，得請求防止之。」
SHIELD 01 // 無權占有或侵奪
1. 所有物返還請求權

當他人無權占有或侵奪所有權人之所有物時，所有權人可以向其要求返還。

SHIELD 02 // 未占有但已造成妨害
2. 妨害除去請求權

雖未占有所有權人之物，但其行為已妨害所有權人的權利行使時，所有權人得請求除去其妨害。

SHIELD 03 // 有妨害之虞（預先防範）
3. 妨害防止請求權

所有權人對於可能會妨害所有權行使的行為（有妨害之虞），可以預先要求他人不得從事該行為。

LIMIT 01 // 民法第 757 條精神

1. 物權必須由法律規定，不能自行創設（物權法定主義）

古羅馬採取「絕對所有權原則」（不干涉個人使用方式與目的）；隨著資本主義社會興起，對所有權的限制成為新趨勢，避免權利過度擴張以保障社會大眾權益。

因為物權優先於債權，又具有保護絕對性，不能由當事人自行約定。因此民法規定：「物權除依法律或習慣外，不得創設」，稱為「物權法定主義」。

LIMIT 02 // 民法第 758 條 ＆ 第 761 條

2. 不動產物權必須要登記（不動產登記生效主義）

相較於動產，由於不動產的市場價值高，因此民法規定不動產的取得、變更、喪失等必須依法登記，且登記後才產生所有權，藉以保障交易安全，稱為「不動產登記生效主義」。

📖 課本小辭典（P.114）所有權移轉：
• 不動產登記生效要件主義（民法§758 I）：不動產物權行為，非經登記，不生效力（專指地政機關所辦理土地登記簿上之登記）。
• 動產交付移轉所有權（民法§761 I）：「動產物權之讓與，非將動產交付（占有的移轉），不生效力。」

TANGIBLE PROPERTY // 有形物權 × 公共利益（P.115）

🌧️ 臺灣「騎樓」建築設計的法理調和

現代社會人與人互動緊密，若完全保障所有權，有時會影響公共利益。例如在臺灣，氣候炎熱潮濕常有雨，在房屋建築上就有了「騎樓」的設計，各戶人家將一樓房屋內縮，保留空間以供行人行走。

INTANGIBLE PROPERTY // 無形財產 × 開放原始碼（P.115）

💻 智慧財產權、合理使用與開放原始碼運動

相對於有形的物權，法律也保障了無形的財產：智慧財產權，保障創作者的權益、肯定智慧的成果並更進一步鼓勵創作。

但漸漸有人質疑智慧財產權的保障反而減緩創作發展，且並非所有人都是為了獲利才願意發明與創造。像是「開放原始碼（Open Source）」的運動便多少帶有反著作權的色彩，追求真正的創作自由。因此法律也應保障一定的合理使用權，同時兼顧創作者權益與人類智慧成果的發展。

📖 課本小辭典（P.115）：開放原始碼 <OPEN_SOURCE/>

原始碼就是在電腦等資訊設備上所使用的應用軟體之原始程式碼。這在商業軟體上，多是無法被使用者所檢視及改寫。開放原始碼運動強調資訊的自由流通與共享，以對抗商業公司的壟斷。

🏛️ CIVIC FORUM // 課本 P.115 公民論壇 《著作權法》第 1 條立法目的

智慧財產權是保障還是限制？應如何與公共利益有所調和呢？

我國《著作權法》第 1 條規定：「為保障著作人著作權益，調和社會公共利益，促進國家文化發展，特制訂本法。」
